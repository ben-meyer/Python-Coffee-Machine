# Python Coffee Machine

My solution to Day 15 of the App Brewery 100 Days of Python course: a console coffee machine.

It takes orders (espresso / latte / cappuccino), checks whether it has enough water, milk and coffee, processes coin payments with change, reports profit, and can be refilled or have resources reported via the secret `report` / `off` commands.

## Run

```bash
python main.py
```
